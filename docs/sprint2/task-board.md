## 3. Формат незалежного аудиту

Кожен учасник перевіряє свої розділи за всіма шістьма критеріями якості вимог:

1. Однозначність.
2. Повнота.
3. Несуперечливість.
4. Простежуваність.
5. Здійсненність.
6. Тестопридатність.

Для кожного знайденого дефекту фіксуються:

- ID вимоги;
- критерій і пункт чек-листа;
- опис дефекту;
- запропоноване виправлення;
- ПІБ автора знахідки.

Один рядок реєстру відповідає одному дефекту.

- `на рецензії` — артефакт готовий і перевіряється;

## 6. Definition of Done Sprint 2

Sprint 2 вважається завершеним, якщо:

- знайдено не менше 20 підтверджених дефектів SRS;
- знайдено щонайменше по 2 дефекти на кожний із 6 критеріїв;
- кожен дефект має ID, критерій, опис, виправлення і автора;
- SRS 1.1 містить журнал змін;
- ID вимог не перенумеровані;
- test-plan містить усі 7 рівнів тестування;
- test-plan містить не менше 15 типів тестування;
- для кожного рівня / типу є Ціль, Опис, пріоритет, інструменти / дані;
- незастосовні типи мають обґрунтування;
- task-board і retro-sprint2.md заповнені.
