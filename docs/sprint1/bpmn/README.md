**Продукт:** П4 «СтейНау» · **Спринт:** 1 · **Дата:** 30.09.2026 · **Автор:** Інженер з тестування

---

## Інструмент моделювання

- **diagrams.net** (app.diagrams.net), вебверсія станом на 30.09.2026.
- Бібліотека фігур: **BPMN 2.0** — вмикається через *More Shapes… → Business → BPMN 2.0*.

## Як відкрити файли

1. Відкрити https://app.diagrams.net
2. *File → Open From → Device* і обрати потрібний `.drawio`.
3. Для перегляду без редактора поруч лежить експорт у PDF.

У репозиторії зберігаються **і вихідний файл** (`.drawio`), **і експорт** (`.pdf`).

| Тип шлюзу | Де застосовано |

| Exclusive (XOR) за даними | 01, 03, 04 |

## Експорт

*File → Export as → PDF*, з опцією **Crop** і без **Fit to page**, щоб модель
лишалася на одній сторінці. Експорт оновлюється після кожної зміни діаграми.
