# BPMN-моделі бізнес-процесів

**Продукт:** П4 «СтейНау» · **Спринт:** 1 · **Дата:** 23.09.2026 · **Автор:** Інженер з тестування

---

## Інструмент моделювання

- **diagrams.net** (app.diagrams.net), веброверсія.
- Бібліотека фігур: **BPMN 2.0** — вмикається через *More Shapes… → Business → BPMN 2.0*.
- Версія редактора: _вказати за Help → About_.

## Як відкрити файли

1. Відкрити https://app.diagrams.net
2. *File → Open From → Device* і обрати потрібний `.drawio`.
3. Для перегляду без редактора поруч лежить експорт у PDF.

У репозиторії зберігаються **і вихідний файл** (`.drawio`), **і експорт** (`.pdf`).

## Типи шлюзів у наборі

За нормативом потрібно щонайменше три різні типи. У наборі використано:

| Тип шлюзу | Де застосовано |
|---|---|
| Exclusive (XOR) за даними | 01, 02, 03, 04 |
| Parallel (AND) | 02 |
| Event-based (за подіями) | 02, 04 |

## Експорт

*File → Export as → PDF*, з опцією **Crop** і без **Fit to page**, щоб модель
лишалася на одній сторінці.
