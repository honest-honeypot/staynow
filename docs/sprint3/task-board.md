- тест-кейсів не менше 25 — **46**;
- усі шість обов'язкових полів заповнені в кожному кейсі — **так**;
- кожен кейс простежується до вимоги SRS 1.1 — **так**;
- усі F- та GUI-вимоги покриті або внесені до переліку непокритих із причиною — **так**;
- усі кейси виконані, у журналі зазначені статус, дата, виконавець, середовище — **так**;
- для кожного failed указано Bug ID, для кожного blocked — причина — **так**;
- звітів про дефекти не менше 10 — **11**;
- щонайменше три різні рівні severity — **п'ять**: Blocker, Major, Normal, Minor, Trivial;
- кожен кейс і кожен звіт рецензовані з позначкою і датою — **так**;
- трекер налаштовано, посилання є в README — **так**;
- `audit.md` заповнений — **так**;
- дошка задач і протокол ретроспективи здані — **так**.
