Метою Спринту 4 є автоматизація перевірки бізнес-логіки системи бронювання готелів StayNow.

Основні завдання:

- Написати юніт-тести JUnit 5 для вимог BL-10–BL-70.
- Забезпечити щонайменше 3 юніт-тести від кожного учасника команди.
- Автоматизувати ключові UI-сценарії за допомогою Selenium WebDriver.
- Виявити та задокументувати дефекти в GitHub Issues.
- Налаштувати запуск тестів через Maven Surefire.
- Підготувати репозиторій до демонстрації.

## 4. План юніт-тестування

### Журавський Владислав

Клас: `PriceCalculatorTest.java`

2. `fridayShouldBeWeekendNight` — перевірка вихідної ночі (BL-30).
3. `sevenNightsShouldGetDiscount` — перевірка знижки 10% за 7 ночей (BL-50).

Статус: 3 тести реалізовано, 2 пройдено, 1 виявив дефект.

### Вориняк Василь

### Оніщук Максим

3. Утримання 100% менш ніж за 3 дні.

### Оліневич Богдан

3. Номер доступний, якщо попередній гість виїжджає в день нового заїзду.

### Валюх Артем

3. Перевірка порогів скасування: 2, 3, 6 та 7 днів.
